# Nexus - Librería Universitaria Responsive

## Descripción
Aplicación web responsive para el catálogo y carrito de compras de la librería Nexus.

## Tecnologías
- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla)
- API REST (mock)

## Funcionalidades
- Visualización de catálogo
- Filtros por búsqueda, categoría y precio
- Vista detalle de libros
- Añadir al carrito
- Reservar libros
- Carrito funcional con localStorage
- Diseño responsive Mobile First

## Responsive
- Mobile (base)
- Tablet (768px)
- Desktop (1024px)

## Accesibilidad
- Navegación semántica
- Alt en imágenes
- Focus visible
- Botones accesibles
