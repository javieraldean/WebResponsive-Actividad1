# Memoria Técnica - Nexus

## Enfoque
Se aplicó metodología Mobile First utilizando Flexbox como sistema principal de maquetación.

## Arquitectura
Se estructuró el proyecto en:
- vistas HTML separadas
- CSS modular
- JS desacoplado por funcionalidad

## Componentes clave
- Card-libro reutilizable
- Header responsive
- Carrito dinámico
- Sistema de filtros

## Responsive
Se implementaron media queries en:
- 768px (tablet)
- 1024px (desktop)

## Persistencia
Se utilizó localStorage para:
- carrito
- reservas

## Integración API
Se consumió API REST para:
- listado de libros
- detalle por id
